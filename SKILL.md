# Anki Cloze Cards — карточки английского для русскоязычных

Скилл превращает любой ввод (слово, фраза, идиома, коллокация, фразовый глагол) в **cloze-карточку Anki в контексте** — одну или несколько, если ввод требует разделения. Единственный артефакт на каждый запрос — **.tsv-файл в папке `new_words/`**; карточка в чат не выводится ни в каком виде. В чате остаётся только короткое подтверждение (или сообщение о дубле).

## Файлы рабочей папки

Скилл работает в текущей рабочей папке пользователя:

- **`All_Words.csv`** — общий словарь всех уже разобранных единиц. Колонки: `Type,Word,POS / Info`, где `Type` ∈ `Word` / `Phrase` / `Phrasal Verb` / `Idiom`. Если файла нет — создай его с одной строкой заголовка `Type,Word,POS / Info`.
- **`new_words/`** — папка с TSV-файлами на импорт. Если её нет — создай.
- Note type для Anki создаётся скриптом [scripts/create_anki_notetype.py](scripts/create_anki_notetype.py) (нужен запущенный Anki с аддоном AnkiConnect). Повторный запуск безопасен: добавляет недостающие поля существующим заметкам (пустыми) и обновляет шаблон со стилями. Запускай его только если пользователь просит настроить Anki.

## Рабочий цикл на каждый запрос

1. **Проверь словарь:** прочитай `All_Words.csv`, приведи ввод к лемме / базовой форме (для phrasal verb — к headword'у без местоимений) и сравни с колонкой `Word` без учёта регистра. Если слово уже есть — НЕ генерируй карточку: ответь коротко, что слово уже в словаре, процитируй найденную строку (`Type` · `Word` · `POS / Info`) и остановись. Этот же прочитанный словарь дальше нужен для поля `Related`.
2. Собери данные из Cambridge Dictionary; для сленга — дополнительные источники (см. «Источники»).
3. Подбери **естественное** предложение и подсказку в пропуск по иерархии (см. ниже).
4. Заполни все поля шаблона: блок из 3–6+ примеров в Example2, русские переводы (SentenceRU, DefinitionRU, Example2RU, RU), промпт картинки в ImagePrompt, соседей из словаря в Related (см. ниже). Примеры — того же значения, что в Sentence. Поля Image и MyExample оставляй пустыми.
5. Собери карточку по полям эталона **внутренне** (в чат не выводи) и механически сконвертируй в TSV-строку(и). Перед сборкой первой карточки в сессии прочитай [references/card-template.md](references/card-template.md) — там полный шаблон полей, эталоны markdown/TSV и правила конверсии.
6. **Сохрани и зарегистрируй:** запиши TSV-строку(и) в `new_words/<слово>.tsv` (пробелы → `_`; один файл на слово; многозначность → несколько строк в этом же файле) и допиши строку(и) `Type,Word,POS / Info` в `All_Words.csv`.
7. **В чат** выведи только короткое подтверждение: что сохранено и куда (имя файла + сколько значений). Саму карточку не показывай.

## Главный принцип карточки

Карточка построена на извлечении в контексте, а не на переводе:

- **Лицевая сторона = предложение с пропуском + поле ввода.** Ученик вспоминает само СЛОВО внутри живого контекста (продакшн), а не делает «русский → английский», и **вписывает его руками**: шаблон держит своё JS-поле ввода (работает и на AnkiWeb), Enter открывает ответ, на обороте ошибочные буквы зачёркнуты рядом с правильным ответом.
- **Оборот = подкрепление:** определение, форма, коллокации, блок примеров, соседние слова из колоды (Related), картинка-ассоциация и русские переводы как скрытая страховка.
- **Оборот заканчивается продакшном:** поле `MyExample` — своё предложение, которое ученик записывает сам через редактор Anki (клавиша `E`). В TSV оно всегда пустое.
- **Monolingual-first, но с подстраховкой.** Русского в пропуске НЕТ. Русский живёт только в своих полях (SentenceRU, DefinitionRU, Example2RU, RU) и на обороте показывается под спойлером `<details>` — это обеспечивает шаблон карточки, в TSV кладётся только текст.
- **Одна карточка = одно значение.** Многозначность → отдельные карточки (строки в одном файле слова).
- **Картинка — на обороте.** Генерируешь не картинку, а англ. **промпт** для неё (поле ImagePrompt); саму картинку пользователь вставляет сам, поле Image всегда пустое.

## Источники

**Основной** — Cambridge Dictionary. **Дополнительные** (только если значение сленговое, NSFW, мемное, региональное или его нет в Cambridge): Wiktionary, Urban Dictionary, Green's Dictionary of Slang, Collins / Merriam-Webster / Dictionary.com.

Нестандартные значения помечай явно: `slang / vulgar / internet / taboo / regional / old-fashioned`, при необходимости с источником — *(slang, источник: Urban Dictionary)*. Обычное и сленговое значение не смешивай; если сильно различаются — отдельные карточки.

## Подсказка в пропуске — иерархия

Синтаксис Anki: `{{c1::ответ::подсказка}}` — текст после второго `::` показывается на лицевой стороне. Подсказка обязана сужать ответ до **уникального** (иначе ученик впишет синоним и не задрилит форму), но без перегруза: «первая буква + один короткий англ. ориентир» — потолок; перевод и часть речи в подсказку не клади.

1. **Стандарт — первая буква + короткий англ. синоним/дефиниция:** `{{c1::oatmeal::o___ cooked oats}}`. Для фраз и фразовых глаголов маскируй **каждое** слово: `{{c1::claw back::c___ b___ recover gradually}}`.
2. **Только первая буква** (`{{c1::oatmeal::o___}}`) — если контекст почти однозначен, но нужно зафиксировать форму.
3. **Пусто** (`{{c1::claw back}}`) — если предложение само делает ответ единственным (жёсткие коллокации, идиомы).
4. **Русский в подсказке — НИКОГДА.** Русский только в RU-полях под спойлером.

## Разделение и объединение

**Отдельные карточки:**
- **Контрастные / смешиваемые пары** (interesting/interested, affect/effect, say/tell, make/do, think of/think about) — это **разные слова**: каждое проверяется по All_Words.csv, идёт в **свой файл** и свою строку словаря. НЕ склеивай в одно предложение: по карточке на член пары, каждый в естественном предложении, где подходит только он. Контраст объясняется на обороте (Form / Example2 показывают вторую форму, один пример в формате «✗ … → ✓ …»). Разбор — в [references/card-template.md](references/card-template.md).
- **Разные значения слова** (polysemy) — отдельная карточка на значение, у каждой свой Sentence, ImagePrompt и контекст; все строки — в **одном** файле слова.
- **POS с принципиально разными смыслами** (*bear* «терпеть» / «медведь») — отдельные карточки.

**Одна карточка:** одно ядро значения, просто употребляется как noun и verb (*gossip*): POS в Form, в примерах метки *(noun)* / *(verb)*, теги — оба. **Если сомневаешься — одна карточка.**

Слово с десятками значений (*set*, *run*, *get*) — бери 3–5 самых частотных по Cambridge отдельными карточками и явно отметь, что список не исчерпывающий. Контекст задаёт значение — работай с ним. Опечатка / несуществующее слово / неизвестная аббревиатура без контекста — короткий переспрос одним сообщением; в остальных случаях уточняющих вопросов не задавай.

## Блок примеров Example2

Каждое значение получает **свои примеры именно этого значения** — не один общий пример на разные значения. Один пример — ничтожно мало: давай **минимум 3 предложения**, для комплексных слов — **4–6 и больше**, через `<br>` в TSV. Примеры должны быть **разнообразными**: разные коллокации, конструкции и контексты одного и того же значения, а не пересказ одного и того же. Для контрастных пар один пример показывает вторую форму («✗ … → ✓ …»). Близкие оттенки внутри значения — каждому свой пример отдельной строкой.

## Связи с уже выученным — поле Related

Слово держится в памяти прочнее, когда встаёт в сетку знакомых слов. `Related` — **2–4 соседа этого значения, взятые ИЗ `All_Words.csv`**: синонимы, антонимы, легко путаемые.

- **Только слова, буквально присутствующие в колонке `Word` словаря** (написание — как в файле). Ты и так прочитал его на шаге 1. Ничего не выдумывай и не бери слов «со стороны», как бы хорошо они ни подходили.
- Соседи **именно этого значения**; у многозначного слова у каждой карточки свой `Related`. Само разбираемое слово не включай.
- Нет подходящих слов в словаре — **поле пустое** (на обороте оно просто не рендерится).
- Формат: позиции через ` · `, у каждой короткое **английское** различение (3–8 слов) — чем сосед отличается, а не «то же самое». Синонимы первыми без метки, затем `<i>opp:</i>` (антоним) и `<i>cf:</i>` (легко путаемое):
  `<b>retrieve</b> — get a thing back, one action, no struggle · <i>opp:</i> <b>squander</b> — lose it carelessly`

Связи фиксируются в момент создания карточки: старая карточка не узнаёт о синониме, добавленном позже. Поле заполняется только у новых карточек; бэкфилл колоды — отдельная задача по просьбе пользователя.

## Своё предложение — поле MyExample

`MyExample` **в TSV всегда пустое**, как `Image`. Его заполняет пользователь во время review через редактор Anki (клавиша `E`), и предложение остаётся в заметке и синхронизируется. Пока поле пустое, оборот показывает заглушку «составь своё предложение»; заполнено — показывает текст. От тебя требуется только пустая колонка в нужном месте.

## Поля карточки (= 16 колонок TSV, по порядку)

Target · Sentence · SentenceRU · Definition · DefinitionRU · Form · IPA · Collocations · Example2 · Example2RU · RU · Image (всегда пустое) · ImagePrompt · Related · MyExample (всегда пустое) · Tags

Полные описания полей, эталон в markdown, эталон в TSV и таблицу конверсии смотри в [references/card-template.md](references/card-template.md) — прочитай его перед сборкой первой карточки в сессии.

Наполнение полей под тип входа:
- **Слово** — Target = лемма; Form = часть речи / неправильные формы / исчисляемость.
- **Фразовый глагол** — Target = **шаблон управления** (*claw sth back*, *check sth out / check out of sth*); Form = separable / inseparable, transitive / intransitive, положение местоимения.
- **Идиома / устойчивое выражение** — Target = фраза целиком; подсказка чаще пустая или очень короткая; Example2 может показать фиксированную форму (артикль, порядок слов).
- **Коллокация / chunk** — как идиома, но без образности; Form может быть пустым; тег `phrase` без `idiom`.

## Теги

Используй **только** эти теги, других в системе нет:

| Категория | Теги |
|-----------|------|
| Часть речи | `verb` `noun` `adjective` `adverb` `conjunction` |
| Тип единицы | `phrase` `idiom` `phrasal-verb` |

- **Слово** → POS-теги (один или несколько): *gossip* (n/v) → `noun verb`.
- **Идиома / фраза** → `phrase` всегда; `idiom` добавляй, только если это образное устойчивое выражение, а не chunk/коллокация.
- **Фразовый глагол** → `phrasal-verb`.

В TSV теги — последнее поле, через пробел.

## Оформление

- **Жирный** (`<b>` в TSV) — **только разбираемое слово/фразу** в Collocations и Example2; в Related жирным идут сами слова-соседи. Переводы не жирни. В Sentence форматирование несёт сам cloze.
- *Курсив* (`<i>`) — POS-метки в примерах (*(noun)*), регистровые пометки (*(slang, AmE)*), кросс-ссылки («не путай с *direct*»).
- **IPA** — всегда оба варианта: `/слово/ (BrE), /слово/ (AmE)`, источник Cambridge; если совпадают — всё равно пиши обе.
- **Язык полей:** Target, IPA, Sentence, Definition, Form, Collocations, Example2, Related, ImagePrompt — английский; SentenceRU, DefinitionRU, Example2RU, RU — русский. Инлайн-метки POS/регистра — английские. В русских переводах слово жирным не выделяй; порядок предложений в Example2RU строго совпадает с Example2.
- **ImagePrompt** — по-английски, развёрнуто: стиль (`photorealistic` для конкретики, `flat 2D vector illustration` / `minimalist editorial` для абстракции), элементы сцены, опционально палитра. Одна сцена = одно значение. Для контрастных пар сцена визуализирует различие.
- **Редкость/регистр** помечай инлайн в Definition или Example2 (*(rare, formal)*, *(old-fashioned)*); тегов для этого нет.

## Формат вывода — жёсткое правило

На каждый запрос — **единственный артефакт: .tsv-файл в `new_words/`**. Запрещено выводить карточку в чат: ни markdown-рендер, ни TSV-блок. Запрещено менять формулировки, примеры и переводы при конверсии полей в TSV-строку — конверсия механическая. В чате допустимы только:
- короткое подтверждение сохранения (имя файла + сколько значений), либо
- сообщение о дубле с процитированной строкой словаря, либо
- короткий переспрос при опечатке/неизвестном вводе.
